==================================================
PERFORMANCE IMPROVEMENTS
==================================================

1) Single-pass streaming hash + transfer
- Sender now streams file bytes and computes hash in the same pass.
- Removed expensive pre-transfer full-file hash pass from hot path.

2) Reduced allocation overhead in send/receive loop
- Uses preallocated buffers and memoryview/readinto/recv_into patterns.
- Lower GC pressure and improved throughput on large files.

3) Progress update throttling improvements
- Progress system updated to reduce excessive UI refresh calls.
- Better behavior under high-speed transfers and large directory sends.

4) WAN socket tuning
- Socket buffer tuning and timeout-related improvements applied in WAN network layer.
- Better stability/throughput over higher-latency links.


==================================================
RELIABILITY & BUG FIXES
==================================================

1) Metadata and transfer validation hardening
- Improved metadata sanity checks and size guardrails.
- Better error handling for malformed/incomplete metadata and timeout scenarios.

2) Hash mismatch handling
- Explicit mismatch signaling between sender/receiver.
- Better UX messaging when algorithm mismatch occurs.

3) Receiver loop behavior and shutdown handling
- Cleaner stop/start receiver controls.
- Reduced busy-loop behavior in server worker lifecycle.

4) Safer path handling in UI input
- Better extraction/normalization for pasted/dropped paths.
- Improved handling for quoted paths, escaped spaces, file:// URIs, and concatenated drops.

5) Directory receive safety
- Better dedupe logic and safer destination handling.
- Reduced risk of accidental destructive directory behavior.
